# data-visualization-lab
This repository contains practical programs and activities for the Data Visualization Laboratory for the academic year 2026–2027. It covers data visualization using Python, R, and Tableau Public.

Experiments
Introduction to Various Data Visualization Tools
Basic Visualization in Python
Basic Visualization in R
Introduction to Tableau and Installation
Connecting to Data and Preparing Data for Visualization
Data Aggregation and Statistical Functions
Creating Scatter Plot Maps in Tableau
Data Visualizations: Charts, Graphs, and Data Mapping
Basic Dashboards
Storytelling in Tableau

Requirements
Install Python 3 and the required Python libraries. Install R for Experiment 3 and Tableau Public for the Tableau-based experiments.

Install Python libraries using:

pip install pandas matplotlib seaborn plotly

How to Run the Experiments
Python Experiments
Clone or download this repository.
Open the project folder in a terminal or Python IDE.
Ensure the required libraries are installed.
Run the desired Python file.
Example:

python Exp2_Basic_Visualization_Python.py
Replace the example filename with the actual filename of the experiment you want to run.

R Experiment
Open the R program in RStudio or another R environment and run the script.

Tableau Experiments
Open Tableau Public.
Connect to the relevant CSV dataset included in the repository.
Follow the steps in the corresponding experiment algorithm.
Create the required charts, maps, dashboards, or stories.
Datasets
CSV files used by the experiments are included in the repository where applicable. Keep each dataset in the appropriate location and ensure that the file paths used in the programs match the actual filenames and folder structure.

Expected Outputs
Depending on the experiment, the outputs may include:

Bar charts, line charts, pie charts, scatter plots, and histograms
Data cleaning and aggregation results
Scatter plot maps and other data visualizations
Dashboards and data stories created in Tableau
Purpose
The purpose of this repository is to provide practical experience in data preparation, statistical analysis, data visualization, dashboard creation, and data storytelling using Python, R, and Tableau.
